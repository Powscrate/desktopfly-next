# Third-party notices

The current app has no third-party NuGet dependencies. It bundles a third-party-derived biological geometry asset, `assets/models/neuromechfly-v2/drosophila.glb`, converted from NeuroMechFly v2 / FlyGym and redistributed under Apache License 2.0. The app embeds `desktopfly-sprite-atlas.png`, a shaded single-pose derivative of that model, plus `rest-pose.json` transforms derived from FlyGym 1.2.1/MuJoCo 3.2.7's documented tripod pose; see the adjacent README for provenance and limitations. A copy of the Apache license is included beside the source model. The upstream conversion was made available by `tac76/fly-brain-simulation`; its NOTICE identifies the source and license. Python mesh/raster packages are only needed to regenerate the checked-in atlas and are not runtime or .NET dependencies. No FlyWire connectome data is bundled.

The application uses .NET 8 / Windows Forms and the .NET base class libraries supplied by the user's .NET runtime or included in a self-contained publish. Consult Microsoft's .NET license and notices for redistributed runtime binaries when packaging. No runtime network requests are implemented.
