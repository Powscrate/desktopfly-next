# Third-party notices

The current app has no third-party NuGet dependencies. Its runtime fly image is user-provided artwork stored at `assets/sprites/fly/`; it is embedded as a transparent PNG resource. The former NeuroMechFly GLB model and renderer assets have been removed from the repository at the user's request. No FlyWire connectome data is bundled.

The application uses .NET 8 / Windows Forms and the .NET base class libraries supplied by the user's .NET runtime or included in a self-contained publish. Consult Microsoft's .NET license and notices for redistributed runtime binaries when packaging. No runtime network requests are implemented.
