# Data provenance

The repository bundles `assets/models/neuromechfly-v2/drosophila.glb`, a 3D adult female *Drosophila melanogaster* mesh converted from FlyGym's NeuroMechFly v2 and simplified by the upstream converter. The source project says its biomechanical model is based on a micro-CT scan of a real adult female fly. `rest-pose.json` contains static neutral part transforms derived from FlyGym 1.2.1/MuJoCo 3.2.7; it contains no motion recording. `desktopfly-sprite-atlas.png` is a four-frame software-rendered derivative of the assembled mesh and is embedded in the Windows app. It is shaded, not UV-textured, and does not represent a measured wingbeat or live 3D renderer. File-level provenance, upstream commits, checksums, limitations, and the Apache-2.0 license copy are in `assets/models/neuromechfly-v2/`.

No FlyWire connectome, neural dataset, or pretrained model is bundled. `data/models/synthetic-escape-v1.json` remains a small, hand-authored description of the two-cell engineering demonstrator; it is not an authentic connectome and is not imported as model data by the runtime. `data/configurations/default.json` is an example settings file.

Future integration must record the dataset/project owner, canonical source URL, release/version/date, license and redistribution terms, schema, extraction steps, mapping choices, missing/unsupported metadata, neuron and synapse counts, and an integrity hash. Large datasets should be downloaded explicitly by the user or managed outside the source tree, not fetched silently at startup.
