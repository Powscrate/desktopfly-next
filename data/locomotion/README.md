# FlyGym walking-kinematics trace

`flygym-untethered-step-v1.json` is a compact conversion of `single_steps_untethered.pkl` from the public FlyGym 2.1.1 repository, commit [`a63dc91a7ce432452e6521c2f3dcc1a7c2c7c6bc`](https://github.com/NeLy-EPFL/flygym/tree/a63dc91a7ce432452e6521c2f3dcc1a7c2c7c6bc). The source repository is licensed Apache-2.0; the full license text is included at `licenses/FlyGym-Apache-2.0.txt`. Credit the NeuroMechFly/FlyGym team (NeLy-EPFL). The corresponding framework paper is Wang-Chen et al., *NeuroMechFly v2: simulating embodied sensorimotor control in adult Drosophila*, Nature Methods (2024), DOI: <https://doi.org/10.1038/s41592-024-02497-y>.

The source asset (18,024 bytes; SHA-256 `1e5b28bb6b3f50ac95a04773ea37af28d05e26d03bd90fdba57fa1b3eacfaf8c`) contains one 45-frame, six-leg, seven-joint step trace with a 3 ms timestep (0.135 s per cycle, about 7.41 Hz). FlyGym describes its preprogrammed steps as extracted from walking recordings; its embedded metadata identifies an aligned, smoothed/interpolated sequence sourced from `data/3D_pose_alfie/clean_3d_best_ventral_best_side.csv`. The JSON retains these recorded joint-angle samples and leg phases; its SHA-256 is `582be4b10e1243cabbfb2af6c9d20e3f70066b2071a0fb50f1b4e22809fbede2`. The FlyGym repository's top-level license is Apache-2.0, but we have not independently verified separate licensing terms for the underlying 3D-pose recording. This attribution records the chain of provenance and does not claim to independently relicense that original recording.

The app cyclically samples those six joint-angle traces. It uses a simple 2D segment projection onto the supplied sprite, not the FlyGym body mesh or MuJoCo, so the displayed limb geometry is still an approximation. Motor-neuron rates modulate gait timing through a modeled interface; they are not validated muscle commands. The selected one-step trace is not a full behavioral recording, locomotion controller, or full fly model.
