# NeuroMechFly v2 Drosophila body mesh

`drosophila.glb` is a 3D adult female *Drosophila melanogaster* biomechanical mesh converted from FlyGym's NeuroMechFly v2 model and simplified with `fast-simplification`. It is a scientific scan-derived anatomical mesh, not a photogrammetry texture set or a fully rigged animation asset.

## Provenance

- Original model: NeuroMechFly v2 / FlyGym, https://github.com/NeLy-EPFL/flygym
- NeuroMechFly v2 states its biomechanical model is based on a micro-CT scan of a real adult female fly, with some body segments adjusted to better reflect anatomical evidence.
- GLB conversion source: `tac76/fly-brain-simulation`, `viewer/public/assets/fly.glb`, commit `7ec43e5121c5e85de92e458d7b32c02e8f7886fa` (repository commit `7ea10330747bd2a1417ad27acca2ae71a7d77bc0`), https://github.com/tac76/fly-brain-simulation/tree/7ea10330747bd2a1417ad27acca2ae71a7d77bc0
- The upstream project's `NOTICE` explicitly identifies this GLB as converted from FlyGym's NeuroMechFly model and identifies the mesh license as Apache-2.0.
- FlyGym source license: Apache License 2.0, copyright 2023–2026 The NeuroMechFly v2 Authors. A copy is included as `LICENSE-APACHE-2.0.txt`.
- SHA-256: `278143b583d4288d5aba20457ad972a7c8d849efecfd5faad6f716a4bae1d1a8`

## Contents and renderer integration

The GLB is about 3 MB and contains 69 named mesh objects, including thorax, head, abdomen segments, eyes, two wings, halteres, antenna segments, and individual leg segments. It has approximately 75,000 position vertices and 452,532 triangle indices (150,844 triangles). It uses per-vertex colors and does not embed texture images, normals, or a rigged skeleton/animation.

`rest-pose.json` records the 69 part transforms from FlyGym 1.2.1's `neuromechfly_seqik_kinorder_ypr.xml` and its documented `pose_tripod.yaml` walking snapshot, generated by MuJoCo 3.2.7. This resolves the model's separate local mesh frames without importing a motion recording. The earlier `pose_stretch` was an initialization pose and left a hind leg unnaturally extended in the side view. The model contains six leg assemblies with coxa, femur, tibia, and five tarsal segments per leg. It has no separately named claw/pulvillus mesh, and no artificial foot or claw has been added. SHA-256: `3315703fe81e7058ddee101629ecd0a0ca6ebd73b7efff37ed1f3b772c6d2995` (the JSON also records and validates the source GLB hash).

`desktopfly-sprite-atlas.png` is a single transparent 320×256 frame baked from the assembled 3D geometry. It uses the source tripod pose without hand-authored joint positions or a fabricated wingbeat. The offline software renderer adds directional diffuse/specular shading, modest per-part color variation, the source wing geometry, and a soft contact shadow. GDI+ rasterizes it into a separate per-pixel-alpha window; the application does **not** load or rasterize the GLB live, provide a 3D camera, or animate a measured gait. The atlas SHA-256 is `a4bdf4617982f5cc17d2eced1e56d5d84f294c91fc7c9453d7d25e582ad28964`. This baked approach avoids a GPU or large render dependency on low-end Windows systems.

The model has no UV texture maps. The atlas's shading/color variation is not a photographic texture or a claim of photorealism. The app draws no substitute anatomy if model loading/rendering fails. The on-screen movement and neural model are still software approximations, not a real fly or validated biological simulation. To regenerate the pose and sprite, install Python with `flygym==1.2.1`, `Pillow`, `trimesh`, and `fast-simplification` (FlyGym supplies NumPy and pins MuJoCo 3.2.7), then run from this directory:

```sh
python tools/export_neutral_pose.py
python tools/render_sprite_atlas.py
```

No FlyWire connectome or other non-commercial scientific dataset is included with this model.
